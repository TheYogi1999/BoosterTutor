# Transition and reward sound auditions

Nine original sketches: T1–T3 transitions, C1–C3 single coin ticks, R1–R3 result finishes. Family 1 is Foley, 2 Arcane, 3 Retro. The three set demos play a transition, six progressively stronger coin ticks and a finish. Preview selections only save local choice codes; they do not change game audio.

Generated by `python3 scripts/make-receipt-auditions.py`, using numpy, scipy and ffmpeg. MP3: 44.1 kHz stereo, 128 kbps. Singles target -24 LUFS / -4 dBTP; comparison demos keep bounded mix levels. Short fades and low-pass filtering avoid hard clicks or sharp high frequencies.

Foley uses existing unmodified Kenney CC0 recordings: `assets/audio/card-fan.ogg` and `card-place.ogg` from [Casino Audio](https://kenney.nl/assets/casino-audio), and `death-previews/source/impactMetal_medium_000.ogg` from [Impact Sounds](https://kenney.nl/assets/impact-sounds). The latter source's pinned mirror and fingerprints are recorded in [the defeat-audition notes](../death-previews/README.md). All additional tones/noise and arrangements are original deterministic synthesis. No branded/game audio is sampled.
