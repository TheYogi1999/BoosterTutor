# Original enemy portraits (v0.89)

`enemies-v89.webp` is an original generated fantasy illustration atlas for Booster Tutor,
with four columns and two rows. There are no card frames, labels or reused game portraits.
The generated PNG is retained in the workspace; the game uses a 1200px WebP conversion.
CSS crops each portrait slightly inward, with proportional scaling, to keep adjacent
cells out of the equally sized battlefield portraits.

Top row, left to right: Emberwing Imp, Mirefang Toad, Copperback Scarab, Dawnmane Cavalier.
Bottom row: Cinderveil Phoenix, Thorncrown Stag, Mooncap Myconid, Abyssal Leviathan.
