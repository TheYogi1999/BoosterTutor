# Original enemy portraits (v0.68)

`enemies-v68.webp` is an original generated fantasy portrait atlas created for Booster Tutor. It replaces the mixed illustration sheets and Scryfall crops for all twenty enemy archetypes. It contains five columns and four rows, with equal 4:5 cells and no labels or card frames. The game uses a WebP encoding at the original resolution; the untouched generated PNG is retained in the workspace. Player avatars keep their existing square illustration sheet, displayed without stretching.

Reading order:

- sprout, wisp, duelist, boar, sprite
- raider, wolf, stalker, bulwark, archivist
- vampire, dragon, tyrant, sphinx, goblin
- goblinArsonist, goblinSneak, rat, saproling, myr
