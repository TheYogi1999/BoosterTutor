# Original enemy portraits (v0.88)

`enemies-v88.webp` is an original generated fantasy portrait atlas for Booster Tutor,
with four columns and two rows. The portraits use equal 4:5 crops without card frames
or labels. Display uses width-based background scaling to preserve image proportions.
The generated original is retained in the workspace; the game uses a 1200px WebP.

Top row: Venomfang Adder, Ossuary Duelist, Gloomwing Bat, Broodweb Weaver.
Bottom row: Stormtalon Raptor, Runebound Colossus, Grave-Tide Oracle, Cindercrest Hydra.

These are original illustrations, not card artwork or reused portraits from other games.
