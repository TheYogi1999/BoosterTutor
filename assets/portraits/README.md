# Enemy portraits

`foes.webp` is an original generated fantasy illustration atlas created for Booster Tutor, with nine equal cells and no card frames. The generated source PNG is retained in the workspace.

Rows, left to right:

- Ember Duelist · Ridge Boar · Mist Sprite
- Bog Stalker · Iron Bulwark · Rune Archivist
- Dusk Vampire · Ash Tyrant · Tide Sphinx

The existing `walkers.webp` remains in use for the player avatars and the five original enemies.
